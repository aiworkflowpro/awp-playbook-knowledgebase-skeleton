# Knowledge Base

> Router for Leo's AI Workflow Pro knowledge base — where everything lives, where to look for it, and how to behave while working here. This is the finished Episode 2 result: eight folders, filled.

## Subdirectory Index

| Directory | Content | Trigger words |
|-----------|---------|---------------|
| `owner/` | Who I am — background, skills, decisions, communication style | Leo, me, my background, my preferences, my story |
| `brand/` | How I sound — AI Workflow Pro identity, positioning, voice, visual assets | brand, voice, tone, identity, positioning, audience |
| `business/` | Where my work lands — YouTube channel, articles, social media platforms | business, YouTube, channel, publish, platform, product |
| `specs/` | My rules — naming, writing, operating conventions — plus `awp-knowledge-management-standard/`, the full standard this knowledge base was built from | rule, standard, convention, naming, checklist, directory pattern, area skeleton, methodology |
| `workflows/` | My pipelines — video creation, publishing, research, operations | workflow, pipeline, process, run, automation |
| `research/` | What I know — topics, references, analysis | research, topic, reference, knowledge, experiment |
| `dashboard/` | Run results — task output, status snapshots, by month | dashboard, report, run result, status, output |
| `inbox/` | Staging area — new files land here, get sorted into the right folder | inbox, staging, new, unsorted, capture |

## Behavior Rules

- **External-facing business only.** Handle what the AI Workflow Pro business shows to the world — videos, articles, social media, research. Never operate in financial, personal, or private areas.
- **Check in when unsure.** If a task touches sensitive information, money, personal data, or a direction Leo should decide, stop and ask before acting.
- **Follow the standards.** Every file created from now on follows the rules in `specs/` — `naming-convention.md` and `format.md`.
- **Current state only.** No file is indexed before it exists; update this router as content is added.
