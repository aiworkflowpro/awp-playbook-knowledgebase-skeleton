# YouTube Script Standard (AWP)

## Scope
All YouTube video scripts for the AI Workflow Pro (AWP) brand, from now on. One script per video. Based on current YouTube best-practice research: hooks, retention, and tutorial structure.

## Rule
Every script follows this structure and these style rules.

**Structure — Hook, Value, Recap, CTA:**

1. **Hook (first 20 seconds).** Open with a pattern interrupt — a direct question or statement about the viewer's real problem — then promise what they will get: "By the end of this video, you'll know..." Name two or three specific things the video covers.
2. **Value.** The body. State the problem first, then walk through clear steps in order. Give each step a timestamp. One idea per section. Add a pattern interrupt every 60–90 seconds — a new example, a question, a change of pace — so attention renews.
3. **Recap.** A quick summary of what was covered. Leave the viewer with one thing they can apply.
4. **CTA.** One natural call to action at the end (subscribe, like, or comment). Never beg, and never ask before the value is delivered.

**Style — professional and concise English:**

- Plain, correct, professional English — no slang, no hype, no filler.
- Spoken-word style: short, punchy sentences that sound natural when read aloud.
- Script length matches target duration: about 130–150 words per minute (a 10-minute video ≈ 1,300–1,500 words).
- No dead air, no long pauses, no unnecessary words. If a sentence stumbles when read aloud, rewrite it.

## Good example
> "You've spent weeks testing AI agents, but none of them actually run your business. In this video, I'll show you the exact workflow I use to automate video topic research — the three steps, the tools, and where it breaks. By the end, you'll have a pipeline you can copy."

## Bad example
> "Hey guys, welcome back to the channel! So today we're gonna talk about some really cool stuff about AI agents, it's gonna be awesome. Um, so basically, like, let's get into it — make sure to like and subscribe!"

## Check
- First 20 seconds: the script opens with a problem or promise, not a greeting. No "hey guys, welcome back" opener.
- All four sections present: Hook, Value, Recap, CTA.
- Read-aloud test: every sentence is short and spoken-natural; no sentence over 25 words.
- Filler check: no "um", "uh", "basically", "like" as filler, no begging for likes before the end.
- Length check: word count ≈ 130–150 × target minutes.
